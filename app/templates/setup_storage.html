Where Should Your Garage Live?

Your tools, photos and manuals are kept as Markdown files and PDFs, with a history of every change.

You can switch between these later in Settings → Storage.

Make a token at GitHub → Settings → Developer settings → Fine-grained tokens: only this repo, Contents: Read and write. Use a private repo. An empty one is filled with the starting point below (don't tick “Add a README” when creating it); one that already has a garage is brought in as is.

If the server's data folder already holds a garage, it's kept and this is skipped.
