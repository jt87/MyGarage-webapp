Where Should Your Garage Live?

Your tools, photos and manuals are kept as Markdown files and PDFs, with a history of every change. You can connect a GitHub backup later in Settings.

Make a token at GitHub → Settings → Developer settings → Fine-grained tokens: only this repo, Contents: Read and write. An empty repo is filled with the starting point below; one that already has a garage is used as is (start from the sample dataset).

If the server's data folder already holds a garage, it's kept and this is skipped.
